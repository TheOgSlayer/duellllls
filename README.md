# DuelPlugin
Paper 1.21 duel plugin: multiple 200x200 arenas, rising fence, breakable blocks, `/duel spec`.

Commands: `/duel <player>`, `/duel accept`, `/duel spec <player>`, `/duel leave`

## Build with GitHub
1. Create a new GitHub repository and upload all these files (keep the folder structure, including `.github`).
2. Open the **Actions** tab. The "Build plugin" workflow runs on every push (or click "Run workflow").
3. When it finishes, open the run and download **DuelPlugin** under Artifacts.
4. Unzip it and put `DuelPlugin-1.0.jar` in your server's `plugins` folder, then restart.
